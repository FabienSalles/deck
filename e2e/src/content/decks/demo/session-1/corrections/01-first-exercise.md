# Correction 1: Getting Started

## Solution

```markdown
## My First Slide

- Point one <!-- .element: class="fragment" -->
- Point two <!-- .element: class="fragment" -->
- Point three <!-- .element: class="fragment" -->

Note: Remember to use fragments for progressive reveal.
```

## Key Takeaways

- Use `##` for slide titles (not `#`)
- Fragments animate bullet points one at a time
- Speaker notes go after `Note:`
